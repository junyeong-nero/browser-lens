Tool categories

Observation
observe_page, check_by_ref, list_tabs, and get_accessibility_tree inspect the current browser state without intentionally changing it.
Interaction
Click, type, scroll, hover, select, check, key, and drag-style tools operate on the current page.
Navigation
open_web_browser, navigate, search, history, reload, and tab switching/closing tools change the browsing context.
Recovery
Back, forward, reload, tab switch, and tab close calls often indicate the agent is recovering from a wrong or stale state.
Waiting
wait_5_seconds and wait_for_ref spend time waiting for page state or an element reference.
